# Cybersecurity Audit
Completed a security audit completed as part of the Google Cybersecurity Professional Certificate program. This project demonstrates my ability to perform a structed security audit, evaluate risks, and produce actionable recommendations aligned with industry frameworks.

## Objectives
-Produce a professional audit report suitable for real-world environments
-Recommend security controls using NIST CISF controls
-Assess organizational assets and risks
-Identify vulnerabilities across systems and processes

## Tools Used
-NIST Cybersecurity Framework
-SIEM log analysis
-Threat modeling principles

## Skills
- Risk Analysis
- Vulnerability Identification
- Control Selection
- Professional Reporting
- Cybersecurity Documentation
